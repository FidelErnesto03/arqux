# ArqUX Documentation — English

This is the single door to the English library. If a document is not listed here, it does not exist for the reader.

**Spanish is the source language.** `docs/es/` holds the canonical corpus; `docs/en/` is its 1:1 mirror — same relative path, same filename, English body. The normative CORTEX specification under `docs/es/especificacion/` is the canonical source; the English twins under `docs/en/especificacion/` are translations. Rule: directory names mirror the ES canon (mirror paths, English content).

## Front-matter contract

Every public document opens with a four-field YAML block:

```yaml
---
doc_type: canon | tutorial | guide | reference | explanation | report
status:   normative | informative | historical
version:  1.0.0        # semver of the product it describes
verified: 2026-11-15   # ISO date of the last check against the code
---
```

- `doc_type`: one type per document. If it does not fit, the document is split — types are never mixed.
- `status`: `normative` mandates, `informative` describes, `historical` archives without force.
- `verified`: a document without a recent verification probably lies.

### Declared exclusions

- Internal material (strategy, operational audits, roadmap, ADRs) lives outside the repository in `ARQUX-internal/`. It is not published.
- `HANDLERS.md` and `PERMISSIONS.md` are generated artifacts — their English twins are emitted by their generators, not hand-translated.

## Contribution rule

New document → pick the folder by `doc_type` → complete front-matter → **add a line to this index** → the `test_docs_consistency` gate validates. A document without an index entry = red gate. A canonical ES document requires its EN mirror — the parity gate (`test_en_es_mirror_parity`) fails otherwise.
